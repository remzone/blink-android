## Проверено на ТВ

STARWIND SW-LED43UG403, Android 11/API 30, 32-битный armeabi-v7a. Перед обновлением сохранён прежний APK; установка выполнена через `install -r` с совпадающей подписью. Сохранены оформление, погода и история Home. Из-за нехватки места Android первоначально отказал в установке; системный `pm trim-caches 512M` освободил временный кеш без удаления приложений и их пользовательских данных.

Проверены:

- установка обоих APK и сохранение подписки после повторного обновления клиента;
- импорт действующей scoped HTTPS-подписки с панели, отображение профиля, срока и revision;
- штатный диалог Android VPN и создание TUN;
- direct DTLS-соединение с сервером и растущие RX/TX;
- HTTPS probe из Android через VPN: успешный ответ, внешний IP совпал с сервером, время около 700 мс;
- навигация пультом к диагностике;
- открытие «Сетевые настройки» сетевой кнопкой Home, получение состояния и срока подписки через signature provider;
- отключение и повторное подключение туннеля непосредственно из лаунчера;
- отклонение `content query` и `content call toggle` от shell без signature permission.

На этой прошивке изменение VPN-сети сбрасывает текущую TCP-сессию ADB; повторный `adb connect` восстанавливает её по тому же LAN-адресу. Штатная Wi-Fi сеть остаётся доступна.

Снимки и журналы проверки находятся только в локальном `work/` и исключены из Git. Проверка VK на самом ТВ приостановлена владельцем: параллельно выполняются очистка и установка приложений другим ADB-сеансом. Не приписывать успешному direct тесту прохождение инфраструктуры VK. Проверка VK из нового ядра на Linux вернула CAPTCHA, см. выше.

## Повторение live acceptance

Только на разрешённом сервере. Создайте вне Git JSON с полями `mobile.VKProfile` (см. native/mobile/vkturn.go), действующими UUID/ссылкой звонка/сервером/сроком и `mode: "direct"` либо `"vk"`:

```bash
cd native
BLINK_LIVE_PROFILE=/absolute/private/profile.json go test -race -run TestLivePacketStackToServer -v ./mobile
```

Секреты из live-профиля не выводятся. Тест не запускается без переменной. Он не заменяет проверку Android на реальном ТВ.
