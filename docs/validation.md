## Повторение раздельной проверки IPv4/IPv6 на ТВ

`tools/netprobe/main.go` — временная standalone-утилита, не часть APK. Для проверенного ARMv7 Android TV:

```bash
mkdir -p work
CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=7 go build -trimpath -o work/blink-netprobe tools/netprobe/main.go
adb -s TV_ADB_ADDRESS push work/blink-netprobe /data/local/tmp/blink-netprobe
adb -s TV_ADB_ADDRESS shell chmod 700 /data/local/tmp/blink-netprobe
# Сначала включите нужный VPN в клиенте и убедитесь, что он ready.
adb -s TV_ADB_ADDRESS shell /data/local/tmp/blink-netprobe >work/ip-families.jsonl
adb -s TV_ADB_ADDRESS shell rm /data/local/tmp/blink-netprobe
```
